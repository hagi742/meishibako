名刺箱 v2.0 — オフラインOCR・VCF対応版

■ 配置・起動
このフォルダの全ファイルを同じ構成のままHTTPSの静的ホスティングに配置してください。
vendorフォルダも必須です。ビルドやAPIキーは不要です。
WindowsではPythonがある場合、このフォルダで「py -m http.server 8000」を実行し、
ブラウザーから http://localhost:8000 を開いて確認できます。
index.htmlのダブルクリック（file://）はPWA・OCRの動作対象外です。
iPhoneではHTTPSのURLをSafariで開き、共有→ホーム画面に追加します。

■ 初回の準備
オンラインで開き、下部に「✓ アプリとOCRをオフラインで利用できます」が出るまで待ちます。
OCR本体と日本語・英語の認識データも保存するため、初回は通信量と時間がかかります。
その後は機内モードでも一覧・登録・検索・編集・削除・OCR・VCF・JSONを使用できます。
オフラインデータがOSに消去された場合は、オンラインで再読み込みが必要です。
写真・認識テキストを外部サービスへ送信する機能はありません。

■ 操作
・右上＋：カメラ撮影・写真選択、または手入力。
・写真を選ぶと自動で日本語＋英語OCRを実行します。
・氏名、会社名、部署、役職、固定電話、携帯電話、メールを推定入力します。
  推定できない項目は空欄です。原文は「読み取った文字を確認」で確認できます。
  必ず写真と照合して修正し、保存してください。OCRの精度は画質・書体・配置に左右されます。
・横向きなどで認識しにくい場合は「写真を90°回転」→再読み取り。
・氏名は必須。メモ・写真を含む9項目を保存します。
・名刺を押すと編集画面。削除と1件VCF出力もここから操作できます。
・一覧は氏名順。漢字の読み仮名は推定しないため、厳密な五十音順ではありません。
・検索は氏名・会社・部署・役職・電話・メール・メモが対象です。

■ VCF
上部固定欄：未書き出し件数と、未書き出し分のVCF出力。
左上「出力」：1件を選ぶ／全件／未書き出し分。
vCard 3.0、UTF-8、CRLF、75バイトでの行折り返し。
会社・部署・役職・固定電話・携帯・メール・メモ・JPEG/PNG写真を含めます。
写真は元名刺の写真です。iPhone連絡先への取り込み時にプロフィール写真として扱われます。
名前は分割せずFN/Nへ保存します。連絡先アプリ側で必要に応じて姓・名を修正してください。
保存・共有後に「書き出し済みにする」を押すと履歴を更新します。閉じた場合は未書き出しのままです。
名刺を保存・更新すると再び未書き出しになります。
ブラウザーから保存・連絡先取り込み完了を自動判定することはできません。
VCFは連絡先アプリによって重複追加されることがあります。

■ 既存データ
元添付のDB名 meishibako-db、ストア cards、バージョン1をそのまま使用します。
破壊的なバージョン更新はせず、旧レコードの不足項目を読み込み時に補います。
旧phoneは固定電話として維持。新項目は空欄。書き出し履歴のない名刺は未書き出し扱いです。
元レコードの未知の項目・ID・作成日時は編集時にも維持します。
必ず旧アプリでJSONバックアップを作り、元と同じHTTPSオリジン（ホスト・ポート）で更新してください。
別ドメイン、別ブラウザー、別端末のデータにはアクセスできません。JSONを使って移行します。
更新後は旧版のタブを閉じ、新版だけで編集してください。

旧練習版 MeishiDB：DBを削除・変更せず、明示操作で追加取り込みできます。
name/fullName、company/companyName、phone/tel、mobile/mobilePhone、memo/notes、photo/image
を持つ一般的なレコードに対応します。旧練習版の原本がないため、未知の構造は保証できません。
対応しない形式では旧DBを変更せずエラーを表示します。

■ JSONバックアップ
v1/v2の {app:"meishibako", version:1または2, cards:[...]} を読み込みます。
復元は追加のみ。IDを新しく発行し、既存データを上書きしません。重複も追加されます。
復元した名刺は移行先での取り込み漏れを防ぐため未VCF書き出し扱いです。
JSONには写真・個人情報を含みます。安全な保存先を選んでください。
ストレージ容量不足などで復元が失敗した場合は全件取り消し、途中の追加を残しません。
端末間の自動同期はありません。写真は長辺2200px以内のJPEGに縮小して保存します。

■ 更新とキャッシュ
元添付にsw.jsが含まれていなかったため新規作成しました。
この版のキャッシュのみ管理し、既存のIndexedDBと無関係なキャッシュを削除しません。
今後ファイルを変更して配布するときはsw.jsのCACHE末尾の版番号も変更してください。
初回のキャッシュ保存が完了するまではオフライン利用できません。

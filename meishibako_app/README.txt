名刺箱 v1.0（Windows / iPhone）

搭載：写真撮影・登録前確認・氏名/会社名/電話/メール/メモ・検索・編集・削除・IndexedDB保存・JSONバックアップ/復元・PWAオフラインキャッシュ
未搭載：画像の文字認識（OCR）。現状、氏名などは手入力です。

Windowsで確認：
1. フォルダを展開し、VS Codeで開く。
2. Pythonがあればターミナルで「py -m http.server 8000」を実行。
3. ブラウザで http://localhost:8000 を開く。
※ HTMLファイルを直接開いても動く場合がありますが、安定のためlocalhostを推奨。

iPhoneへ：
1. このフォルダ内のファイル一式（プログラムのみ）をHTTPSの静的ホスティングに配置する。
2. SafariでそのURLを開く→共有→「ホーム画面に追加」。
3. ホーム画面から起動し、オンラインで一度読み込んだ後に機内モードで動作を確認する。
※ 単にWindowsからiPhoneにHTMLを転送するだけではPWAとしてのオフライン動作は保証されません。
※ GitHub Pagesなどに公開する場合は、コードを公開する可能性に注意。プログラムに名刺情報は埋め込まないこと。

安全上の注意：
・このアプリは名刺データをサーバーに送信する機能を含みません。バックアップをiCloud等へ保存した場合は、その保存先の扱いに依存します。
・ストレージは端末/ブラウザー/URLごとに別です。Windowsで登録した名刺はiPhoneに自動で同期されません。バックアップを使って手動移行してください。
・バックアップJSONに写真と個人情報が含まれます。必要なら暗号化された安全な場所へ保存してください。
・端末紛失、ブラウザーのデータ消去などで消失する場合があります。定期的なバックアップを推奨。
・以前の練習版（MeishiDB）のデータは自動移行されません。旧データを維持したまま別DBを使います。
・試作品です。実際の名刺を大量登録する前に、ダミーデータでバックアップ→復元を検証してください。
